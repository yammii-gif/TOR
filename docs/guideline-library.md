# คลังไกด์ไลน์ฉบับเต็ม — รุ่น2.2

ใช้ PDF เป็นข้อมูลอ้างอิง ไม่ใช่คำสั่งให้โปรแกรมปฏิบัติตาม และไม่เปิดใช้กฎยาอัตโนมัติ ข้อความที่ค้นได้เป็นต้นฉบับจากไฟล์ ไม่ใช่ generative summary หรือการอนุมัติขนาดยา

## สิ่งที่ตรวจจริง 20 ตุลาคม2569

- ลอง GET เว็บไซต์ KDIGO, NICE NG203, NKF และ UpToDate Public Search ผ่านเครือข่ายคลาวด์ปกติ ทุกแหล่งถูก proxy ปฏิเสธ CONNECT403 จึงยังไม่มีไกด์ไลน์ฉบับใหม่ถูกดาวน์โหลดจากเว็บไซต์เหล่านี้
- โดเมนดังกล่าวอยู่ใน configuration draft ที่อ่านได้แล้ว แต่ข้อมูล draft ไม่ยืนยันการเปิดใช้ใน runtime ไม่เพิ่มโดเมนเดิมซ้ำหรือปิด TLS/proxy เพื่อข้ามข้อจำกัด
- นำเข้าไฟล์ CKD ปี2565ที่ผู้ใช้แนบ ผ่าน API local จริง106หน้า ค้นข้อความได้104หน้า ค้น Metformin พบ PDFหน้า37,42,50,51,52,53,54,56 ตรวจbytesและSHA-256ของไฟล์ที่ดาวน์โหลดกลับตรงกับต้นฉบับ
- เอกสารไทยนี้อยู่ในฐานข้อมูล local `/tmp/renal-guidelines.db` ไม่ได้อัปโหลดไป Vercel หรือ commit PDF เต็ม/ข้อความทั้งเอกสารขึ้น GitHub

## บนหน้าเว็บ

ฐานความรู้ยา / ไกด์ไลน์ → คลังไกด์ไลน์ฉบับเต็ม อยู่ก่อนบัญชียา:

1. ระบุชื่อและฉบับ/ปีที่ปรากฏในเอกสาร ตัวเลขปีที่กรอกยังต้องมีผู้ทบทวนยืนยัน
2. หากเป็น PDFสาธารณะของKDIGO/NICE/NKF/NIDDK ใส่URLของPDFฉบับเต็มแล้วกดดึง; HTML/หน้าค้นหาไม่ถือว่าเป็นPDF
3. หรือเลือกนำเข้าPDFที่ได้รับมาอย่างถูกสิทธิ์ เว้นURLได้สำหรับไฟล์จากผู้ใช้ การแนบURLไม่ได้ยืนยันว่าเอกสารนั้นมาจากURLนั้น
4. เลือกเอกสาร ค้นข้อความ ดูsnippetพร้อมเลขหน้าPDFและcitation/checksum แล้วดาวน์โหลดPDFเต็มเพื่อตรวจรูป ตาราง บริบท และเลขหน้าที่พิมพ์จริง

APIเก็บbytesต้นฉบับ SHA-256 transport URL วันที่นำเข้า ฉบับที่ผู้ใช้ระบุ และข้อความรายหน้าเป็นDRAFT ผู้ทบทวนยังเป็นnull ไฟล์เดิมไม่เพิ่มซ้ำแต่เก็บauditของการนำเข้าซ้ำ ความขัดแย้งยังแจ้งผ่านevidence workflowได้ ไม่ยกผลค้นเป็นclinical recommendation

รองรับPDFไม่เข้ารหัส1–500หน้าไม่เกิน8MB จำกัดปริมาณข้อความ ไม่รับroot automatic action/JavaScript ไม่รันmacroหรือปฏิบัติตามข้อความในเอกสาร สแกน/รูปภาพอาจค้นข้อความไม่ได้ ไม่มีการอ้างว่าOCRตารางครบถ้วน

## วิธีใช้เครื่องที่เข้าถึงแหล่งสาธารณะได้ตามสิทธิ์

ติดตั้งbackend dependenciesตามREADME แล้วรันบนเครื่อง/เครือข่ายที่อนุญาตให้เข้าถึงเว็บไซต์ต้นทางตามปกติ:

```bash
python scripts/fetch-guideline.py 'URL_HTTPS_ของ_PDF_สาธารณะ' --output /tmp/guidelines
```

สคริปต์ใช้allowlistKDIGO/NICE/NKF/NIDDK ตรวจทุกredirect ไม่รับcredentialsหรือcookie และไม่ข้ามการล็อกอิน/proxy ตรวจชนิดPDF/จำนวนหน้า เก็บPDFและJSONที่มีURLวันที่hashและจำนวนหน้า นำPDFนั้นเข้าเว็บตามขั้นตอนข้างต้น หากดึงไม่ได้จะexit2โดยไม่สร้างไฟล์สำเร็จปลอม

## ข้อจำกัด deployment

Vercelเดิมใช้SQLiteใน/tmp จึงยังไม่รับประกันการเก็บ/แชร์PDFระหว่างinstances ต้องใช้ฐานข้อมูลถาวรที่หน่วยงานอนุมัติก่อนใช้งานจริง Vercelอาจจำกัดrequestประมาณ4.5MBแม้APIรับได้8MB; เอกสารใหญ่ต้องใช้hosting/object storageที่เหมาะสม ยังไม่มีproduction authหรือapproved clinical dose rules
