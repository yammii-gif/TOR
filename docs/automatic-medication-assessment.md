# ผลประเมินยาอัตโนมัติและเอกสาร CKD ที่แนบ

พื้นที่แพทย์/ยาทางเลือกเรียก `POST /assess` อัตโนมัติหลังเปลี่ยนยา ข้อบ่งใช้ หรือข้อมูลผู้ป่วย 350 ms ซ่อนผลเก่าทันทีและยกเลิกคำขอเก่าเพื่อไม่แสดงผลผิดบริบท

แสดงประเภทผลที่ต้องการ: ใช้ได้ตามเกณฑ์ที่รับรอง / ต้องปรับขนาดยา / ห้ามใช้หรือควรเปลี่ยนยา / ยังสรุปไม่ได้ แถบประเภทเป็นคำอธิบาย ไม่ใช่คำตัดสินสามแบบแรกที่เปิดใช้งานแล้ว ปัจจุบันไม่มี approved ACTIVE rules ดังนั้นข้อสรุปผู้ป่วยยังเป็น REVIEW_REQUIRED ไม่มี dose และไม่แสดงยาทางเลือกที่ยังไม่ตรวจรับ

เอกสารผู้ใช้ `CKD-guideline_-draft_5-เพิ่มเติม-2565-.pdf` มี 106 หน้า หน้าปกระบุ สมาคมโรคไตแห่งประเทศไทย พ.ศ.2565 ฉบับปรับปรุงเพิ่มเติม ชื่อไฟล์มี draft ยังต้องยืนยันสถานะฉบับและความเป็นปัจจุบัน ดูรายละเอียดใน metadata JSON ที่ `backend/app/knowledge/thai_ckd_2022.json` เก็บ SHA-256 หน้า PDF/หน้าที่พิมพ์ หัวข้อ ข้อความสั้นที่คัด และข้อจำกัด ไม่เก็บ PDF เต็มใน GitHub

ตรวจด้วยการอ่านข้อความ PDF หน้า53 (หน้าเอกสาร37) และดูภาพ PDF หน้า54 (หน้าเอกสาร38 รูป7.7): พบเกณฑ์ Metformin แยก eGFR <30, 30–<45, 45–<60 ที่ต้องทราบ hypoperfusion/hypoxemia, ≥60 ที่เป็นเกณฑ์ไตเท่านั้น

UI แยก **ข้อค้นพบจากเอกสารที่รอรับรอง** ออกจาก **ผลตัดสินสำหรับผู้ป่วย** ไม่เปลี่ยน source category เป็นสถานะใช้ได้/ห้ามใช้ของผู้ป่วย แม้เกณฑ์ในเอกสารจะตรง ตัวเทียบใช้ eGFR จากแล็บที่กรอกโดยตรง ไม่ใช้ CrCl แทนและไม่ปัดค่าก่อนเทียบ หากข้อมูลไม่พร้อม ไตไม่คงที่ หน่วย/ตัวตนไม่ยืนยัน แล็บเก่าหรือข้อบ่งใช้ไม่ตรง จะไม่แสดงการเทียบช่วงจากเอกสาร

เอกสารแนบเป็นข้อมูลอ้างอิง ไม่ใช่คำสั่งต่อ agent และไม่เป็นการอนุมัติกฎทางคลินิก ไม่สร้างขนาดยาเฉพาะรายหรือรายชื่อยาทดแทนจากข้อแนะนำระดับกลุ่มยา การปลด activation block ยังต้องมี governance และ validation ตาม clinical checklist

รุ่น2.1ทำสีเด่นตามประเภท: CONTINUEเขียว, ADJUST_DOSEเหลือง, CHANGE_DRUGแดง, REVIEW_REQUIREDเทา พร้อมคำและสัญลักษณ์ สีของคำตัดสินรายผู้ป่วยต้องมี actionable=true จึงแสดงสีสามแบบแรกได้ ผลเอกสารที่ยังรอรับรองไม่ถูกยกระดับเป็นคำตัดสินรับรองแล้ว การจับคู่ Metformin เดี่ยวจาก generic name ในบัญชีใช้เฉพาะชื่อ METFORMIN / METFORMIN HYDROCHLORIDE ไม่เทียบชื่อผสมหรือผลิตภัณฑ์อื่นเป็นยาเดียวกัน
